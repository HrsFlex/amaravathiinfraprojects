# Amaravathi Infra Projects

Independent static website for real estate, plots/flat enquiries, construction and development in Amaravati, Andhra Pradesh. This is a separate project from Space-interior.

## Preview

Run `python3 preview.py --port 4174` in this folder, then open http://127.0.0.1:4174/.

No installation or build step is required. Files: `index.html`, `styles.css`, `script.js`, `research.html`, `assets/`, `preview.py`.
